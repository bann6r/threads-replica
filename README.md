# Threads archive replica

A standalone, local-first Threads-style profile archive built with HTML, CSS, and JavaScript.

## Run locally

Serve this directory with:

```bash
python3 -m http.server 8000
```

Open http://localhost:8000.

## Customize

- Edit `profile.xml` for the profile name, username, bio, follower count, avatar, and follow URL.
- Edit `posts.xml` to add posts. Keep newest posts first.
- Put avatar and post media files in this repository and reference them with relative paths.

This is an independent archive, not affiliated with Threads. The archive reads local XML files and does not connect to a Threads account.
